# AfterVisitingHours
After Visiting Hours is a Unity based horror game where the player takes on the role of a night shift security guard who is trapped in an abandoned hospital. This hospital performed unethical acts on its patients which made them form into monsters. The player must restore power, avoid and attack monsters, and escape to survive.
